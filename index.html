// CORE CAPABILITIES

Built for Terminal Power Users & Agents

01 / SPEED

Sub-10ms Startup

Zero Python runtimes, zero Docker daemons. Single statically linked Rust binary that starts in milliseconds and consumes virtually no memory.

02 / STORAGE

Normalized SQLite Engine

Raw text lives strictly once in contexts. Compact binary vectors live in embeddings. Scans numbers in RAM, fetching text only for top-k winners.

03 / EMBEDDINGS

Dual-Tier Intelligence

Leverages local Ollama (nomic-embed-text 768-dim) when online, with an automatic fallback to 256-dim subword feature hashing when offline.

04 / INTERFACE

Flexible Top-K Syntax

Query top results intuitively with shorthand flags: --1, --3, --5, or -k 10. Formatted for high readability and pipe friendliness.

05 / UNIX NATIVE

Pipes & Redirection

Fully compliant with Unix philosophy. Pipe outputs directly: cat err.log | hmc --save - --vec and redirect hmc --query "..." > context.md.

06 / PRIVACY

100% Local & Private

Your notes and memories never touch external APIs or cloud providers. Stored in ~/.hmc/hmc.db with zero tracking or telemetry.

// SYSTEM DESIGN

Normalized Two-Table Architecture

INPUT

CLI / Stdin

Accepts raw text or pipe: hmc --save "..." --vec

ENGINE

Dual Embedder

Ollama (768-dim) or Subword Hashing (256-dim)

STORAGE

SQLite (hmc.db)

contexts (Text) <--FK--> embeddings (BLOB)

OUTPUT

Vector Scan

Scans binary float vectors, ranks cosine similarity, loads winning text.

// RECIPES

Common Terminal & AI Workflows

Retrieve relevant knowledge from hmc and pipe it into a local LLM in a single terminal line:

# 1. Pipe retrieved context straight to Ollama
(echo "Based on this context, summarize the key points:"; hmc --query "artificial intelligence" --3) | ollama run llama3.2

# 2. Pipe Ollama answer back into memory:
ollama run llama3.2 "Explain Docker multi-stage builds" | hmc --save - --vec

Handoff terminal context between tabs without copy-pasting:

# Tab 1: Save compilation error or server log
cargo test 2>&1 | hmc --save -
# Output: Saved context with ID: 4a7b9c1d

# Tab 2: Load in another pane or remote SSH window
hmc --load 4a7b9c1d

Add a smart recall helper function to your ~/.bashrc:

ask() {
  local query="$1"
  local context=$(hmc --query "$query" --3 2>/dev/null)
  
  ollama run llama3.2 <<EOF
Context from my notes:
$context

Question: $query
EOF
}
// REFERENCE

CLI Command Reference

Command Description Example
--save <CONTENT> Save context to contexts table; returns 8-char ID hmc --save "User preferences"
--vec Flag to compute and index vector embedding into embeddings table hmc --save "Note" --vec
--load <ID> Retrieve raw context by full ID or prefix hmc --load 5937969c
--query <QUERY> Semantically search memory using cosine similarity hmc --query "database optimization"
--<K> / -k <K> Specify top K matches to return (e.g. --1, --5) hmc --query "rust" --5
- Read content from standard input (pipe support) cat notes.txt | hmc --save - --vec
